# ☕ Steam & Stories Cafe Website

## Overview
Steam & Stories is a modern and responsive cafe website designed to provide customers with an engaging digital experience. The website showcases the cafe's menu, signature dishes, beverages, desserts, chef profiles, customer reviews, reservation system, and contact information through an elegant and user-friendly interface.

## Features
- Responsive and modern UI design
- Interactive menu with food and beverage sections
- Table reservation system
- Login and booking pop-up forms
- Search functionality for menu items
- Customer reviews section
- Chef profiles and cafe story section
- Smooth scrolling and animations
- Mobile-friendly design

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Google Fonts
- Responsive Web Design
